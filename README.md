# vapor-wares/homebrew-apps

Homebrew tap for Vapor Wares apps.

## Setup

```bash
brew tap vapor-wares/apps
```

## Install

```bash
# The store app
brew install --cask vapor-wares

# Apps directly
brew install --cask hello-world
brew install --cask hello-world-google
```

## Available casks

| Cask | App | Version |
|---|---|---|
| `vapor-wares` | vapor-wares.macos.release.app | 0.2.1 |
| `hello-world` | Hello World.app | 1.0.0 |
| `hello-world-google` | Hello World Google.app | 1.0.0 |

## Tap this repo

This directory maps to: `https://github.com/vapor-wares/homebrew-apps`

```
brew tap vapor-wares/apps https://github.com/vapor-wares/homebrew-apps
```
